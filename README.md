# RAISE-Vision
**Robotic Autonomous Imaging Surface Evaluator for Vision Applications**
An automated platform for contact angle (CA) measurement on curved hydrogel surfaces, developed for standardized *in vitro* contact lens wettability analysis throughout air exposure.

## Overview

Existing sessile drop contact angle measurement protocols for contact lenses suffer from poor repeatability and comparability due to inter-laboratory and inter-operator variation (drying method, time to measurement, droplet volume, etc.). RAISE-Vision addresses this by combining custom 3D-printed hardware with an automated liquid-handling workflow and a custom image-processing pipeline, removing operator dependence from both sample preparation and CA analysis.

This repository contains the hardware designs, control software, and image analysis scripts used to build and run the RAISE-Vision platform, along with the benchmarking data and statistical analysis reported in the associated manuscript.

RAISE-Vision builds on the RAISE platform (Nazeri et al., *Digital Discovery*, 2026) for automated formulation-linked wettability measurement, tailoring it for curved contact lens substrates.
