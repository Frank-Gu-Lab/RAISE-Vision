# Hardware

This folder contains the mechanical design files (STL) for the RAISE-Vision automated platform. Parts are organized into three subfolders.

## Folder structure

---

### Drypad

Assembly for holding KimWipes to precisely dry droplets on the contact lens between experiment cycles.

| File | Description |
|---|---|
| `20ul_Adapted_Drypad.STL` | Main drypad body, adapted for 20 µL pipette attachment |
| `Drypad_Tip_Rack.STL` | Holder that accomadates 12 seats for drypads |
| `Drypad_Retaining_Ring.STL` | Retaining ring that secures the KimWipe in place |

---

### Lens Mount

Mount for the contact lens; base curve is designed for 8.5 mm.
| File | Description |
|---|---|
| `Lens_Mount.STL` | Main contact lens mount |
| `Lens_Mount_Holder.STL` | Holder that secures the lens mount to the stage |


---

### Stage

Base stage for the experiments on the RAISE-Vision platform.

| File | Description |
|---|---|
| `RAISE_Vision_Stage.STL` | Main stage platform |


---


## Design source

STL files for each part are included in their respective subfolders above.
